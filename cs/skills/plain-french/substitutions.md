# Replacements

The words and phrases below make a French text heavier without adding meaning. Replace them. The
left column is what `check.mjs` looks for; keep both columns in step when you edit this file.

## Heavy phrases

| Instead of | Write |
|---|---|
| afin de | pour |
| à l'heure actuelle, actuellement | maintenant |
| au niveau de | dans, sur, pour (say which) |
| dans le cadre de | pour, pendant |
| de manière à, de façon à | pour |
| du fait de, en raison de | à cause de, parce que |
| effectuer, procéder à | faire, or the verb itself (« vérifier », not « procéder à la vérification ») |
| en amont | avant |
| en aval | après |
| en termes de | pour, en (say which) |
| être en mesure de | pouvoir |
| il convient de, il est nécessaire de, il faut | the imperative: « Faites… » |
| il s'agit de | c'est |
| mettre en place | installer, créer, organiser (say which) |
| mettre en œuvre | appliquer, faire |
| nécessiter | demander |
| par le biais de, par l'intermédiaire de | par, avec |
| permettre de | the direct verb: « Le filtre trie… », not « le filtre permet de trier… » |
| s'avérer | être |
| suite à | après |
| un certain nombre de | the number |
| à noter que, il est à noter que | (delete) |
| en effet | (delete, or « car ») |

## Anglicisms and false friends

| Instead of | Write |
|---|---|
| adresser (un problème) | traiter |
| challenger | mettre à l'épreuve, contester |
| checker | vérifier |
| deadline | échéance, date limite |
| débugger | corriger |
| éventuellement (meaning « finally ») | finalement |
| faire sens | avoir du sens |
| feedback | retour |
| impacter | toucher, changer, modifier (say which) |
| implémenter | réaliser, coder |
| merger | fusionner |
| process | procédure, démarche |
| release | version |
| reporter (un bug) | signaler |
| solutionner | résoudre |
| supporter (meaning « handle ») | accepter, prendre en charge |
| update | mise à jour |

## Vague words

| Instead of | Write |
|---|---|
| certains, certaines | the number, or the names |
| divers, diverses | the list |
| quelques | the number |
| assez, plutôt, relativement | the measure, or delete |
| etc. | the full list, or « par exemple » before a partial list |

## Words that stay

The technical names of the reader's domain stay, in English when that is their usual name: pull
request, token, commit, API, OKR. Gloss them once when the reader can be a non-specialist.
